# AI Studio

محیط وب یکپارچه برای استفاده از دو مدل اصلی پروژه: گفت‌وگوی متنی و تولید تصویر. رابط کاربری فارسی است و هر دو ابزار در یک صفحه و دو زبانه در دسترس‌اند.

## امکانات
- **گفت‌وگوی متنی:** `mlabonne/Daredevil-8B-abliterated` با بارگذاری ۴ بیتی و پاسخ جریانی.
- **تولید تصویر:** `John6666/ebara-pony-v1-sdxl` همراه با VAE `madebyollin/sdxl-vae-fp16-fix` و زمان‌بند Euler Ancestral.
- تنظیم پرامپت، پرامپت منفی، نسبت تصویر، Steps، CFG و Seed.
- یک رابط وب واحد با دو زبانه چت و تصویر.
- مدیریت حافظه: هنگام جابه‌جایی بین چت و تصویر، مدل بخش دیگر از حافظه GPU آزاد می‌شود تا احتمال کمبود حافظه کاهش یابد. در نتیجه اولین استفاده بعد از جابه‌جایی ممکن است دوباره زمان بارگذاری نیاز داشته باشد.
- GitHub Actions برای تست کد و نگهداری ۳۰ اجرای اخیر workflowها.

## سریع‌ترین روش اجرا در Google Colab
1. نوت‌بوک [AI Studio در Colab](https://colab.research.google.com/github/studio1111/AI/blob/main/colab/AI_Studio_Colab.ipynb) را باز کنید.
2. از **Runtime → Change runtime type** یک GPU انتخاب کنید. دسترسی رایگان به GPU تضمین‌شده نیست.
3. سلول‌های نصب و بررسی GPU را به‌ترتیب اجرا کنید.
4. سلول آخر را اجرا کنید تا وب‌اپ یکپارچه بالا بیاید.
5. لینک عمومی Gradio که نمایش داده می‌شود را باز کنید. در همان صفحه می‌توانید بین «گفت‌وگوی هوش مصنوعی» و «ساخت تصویر» جابه‌جا شوید.

## اجرای روی سرور یا رایانه دارای GPU
```bash
pip install -r requirements.txt
python app.py
```
برای اجرای مستقیم رابط‌های جداگانه همچنان می‌توانید از `python chat.py` یا `python image.py` استفاده کنید.

## تست‌ها
```bash
python -m compileall -q app.py chat.py image.py studio_utils.py
python -m pytest -q
```

## نکات مهم
- برای بارگذاری این مدل‌ها به GPU سازگار نیاز است؛ اجرای کامل روی CPU بسیار کند خواهد بود.
- مدل‌ها هنگام اولین استفاده دانلود می‌شوند و ممکن است چند دقیقه زمان ببرد.
- لینک اشتراکی Gradio می‌تواند برای هر دارنده لینک قابل دسترسی باشد؛ اطلاعات خصوصی وارد نکنید و پس از اتمام، نشست Colab را متوقف کنید.
- شرایط استفاده و مجوز هر مدل را در صفحه رسمی آن در Hugging Face بررسی کنید.
